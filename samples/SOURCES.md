**Note:** the EXIF `DateTimeOriginal` timestamps on these files were set
synthetically (not the images' real capture/publication dates) so the set
has a deliberate, staggered chronological order that differs from
alphabetical filename order — this lets tests and manual experiments
actually distinguish `order = "timestamp"` from `order = "filename"`.
